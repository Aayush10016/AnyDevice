# Contributing

Run `npm ci`, `npm test`, `npm run build`, `cargo fmt --manifest-path src-tauri/Cargo.toml`, and `cargo test --manifest-path src-tauri/Cargo.toml` on a prepared Windows build host. Explain observations separately from hypotheses. Each new diagnostic rule needs required evidence, explicit abstention cases, safe recommendations, limitations and synthetic fixture coverage.

Never commit live hardware inventories, tokens, private keys, executable credentials, or fabricated screenshots. No arbitrary shell commands or device modifications belong in v0.1. Test fixtures must remain outside production imports. Update privacy and report-schema documentation for changed fields. Include actual checks and limitations in PRs.
