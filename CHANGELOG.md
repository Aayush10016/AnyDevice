# Changelog

## 0.1.0 — draft Windows candidate

- Initial Tauri 2 / React desktop implementation with fixed read-only PnpDevice discovery.
- Typed normalization, deterministic findings, raw inspection and conservative JSON sanitization.
- Search, filters, overview/activity, diagnostics, report preview/save and local appearance preferences.
- Synthetic fixtures, domain/component tests and Rust boundary tests.
- Windows NSIS build and draft-release workflow, privacy/security/contribution docs.

Windows CI verified packaging, silent installation, binary integrity, installed launch and uninstallation. The standalone also launched on the development host. Manual visual/accessibility and physical-device interaction checks remain required. No stable release or signing is claimed. Use semantic versioning; schema version is independent of application version.
