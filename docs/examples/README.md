# Synthetic examples

Every example in this directory is explicitly synthetic. Names, identifiers, timings, annotations and byte structures are invented fixtures. No real device inventory or protocol capture is included. The Windows source labels describe the normalized schema under test and do not turn fixture observations into real hardware evidence.

The v1 sanitized report preserves the original schema. The v2 diagnostic, investigation and binary-analysis examples were generated by the current domain code and validated against their corresponding JSON schemas. Raw examples use obvious synthetic identities/annotations so their purpose remains visible. No parser or confirmed format is supplied.
